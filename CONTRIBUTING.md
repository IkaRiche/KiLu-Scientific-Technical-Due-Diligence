# Contributing to a public evidence index

The contribution surface is deliberately narrow. Welcome contributions include:
- correcting a public claim/source mismatch or a broken link;
- proposing falsifiable, non-sensitive reviewer questions;
- making the public explanations more precise or accessible;
- improving public-documentation integrity checks.

**Do not** submit private source code, experimental raw data, internal SHA or branches, keys, operational target details, customer identifiers, unpublished inventions, vulnerability proof-of-concepts or patent claims. Do not use this repository as a bug bounty or penetration-test authorization.

For each claim correction, identify the claim ID, publicly inspectable source if one exists, the narrower proposed interpretation, and any contradicting evidence. A private source is not automatically a publicly independently verifiable source.

Changes to public claims require reviewer scrutiny; automated documentation checks cannot certify the underlying science. Proprietary rights remain reserved. See [LEGAL](LEGAL.md) and [SECURITY](SECURITY.md).
