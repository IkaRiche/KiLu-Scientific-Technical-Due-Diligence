# KiLu — полномочия для автономного исполнения

<p align="center"><img src="assets/kilu-hero.svg" width="100%" alt="KiLu — полномочия для автономного исполнения"></p>

**Публичный индекс технических доказательств и due diligence** · [English](README.md) · [Навигация](docs/00_START_HERE.md) · [Реестр утверждений](evidence/CLAIMS_REGISTER.csv) · [Ограничения раскрытия](docs/07_DISCLOSURE_BOUNDARY.md)

> **Агент не должен самостоятельно назначать себе полномочия на исполнение.**

KiLu исследует и реализует отдельный контур исполнительных полномочий. Планировщик предлагает действие, AegisAI оценивает допустимость, человек может подтвердить его, KiLu выдаёт ограниченный грант, исполнитель проверяет полномочия *до* действия, а отчёт и receipt обеспечивают проверку в установленной области.

**Это публичный индекс доказательств, а не выпуск закрытого исходного кода, патентных материалов или готовая оферта о продаже.** Методология основана на [публичном due diligence STASYS/LMA](https://github.com/IkaRiche/LMA-Scientific-Technical-Due-Diligence); сами исследования и объекты IP не смешиваются.

## Что проверяется

| Направление | Подтверждённая область | Не установлено |
|---|---|---|
| Ранее реализованный Android | Исторические проверки биометрического подтверждения, создания задачи, исполнения и DONE (R1/E2) | Новая физическая церемония V2 |
| CREG-001/002 | Приватный CI: Cloud → компилируемый Linux Hub → одно контролируемое действие → JTI → Go Offline Verifier | Производственная развёртка, глобальная гарантия ровно одного побочного эффекта |
| CREG-003 | Публичные JVM-тесты формата подписания V2 и приватные SQLite-тесты против подмены | Сквозное AegisAI Class A → Android V2 → KiLu; аппаратная неизвлекаемость Ed25519 |
| Публичный SDK | Демонстрационные mock-интеграции и документация | `ALLOW` от legacy `/v1/intent` не является полномочием на исполнение |

Приватные результаты описаны как **внутренние наблюдения**, а не воспроизводимые внешним читателем доказательства. Зеленый CI доказывает только выполнение указанных тестов.
